🌟 Introduction & Core Value Proposition

Who is this tool for?

This plugin was designed by and for BIM Managers, BIM Coordinators, Modelers (HVAC, Plumbing, Electrical, Architecture), and Company Executives.

What is its main mission?

In the BIM world, clash detection and resolution (creating openings, communication) are time-consuming processes that are extremely costly for companies. SmartBimPeï eliminates these bottlenecks through:

  • Intelligent Automation: Forget creating openings manually one by one. This plugin handles complex network fusions and curved walls.
  • Standardized Communication: By leveraging OpenBIM standards (BCF), it facilitates communication with external teams on platforms like BIMcollab or BIM Track.
  • Management Visibility: A decision-making dashboard allows executives to evaluate the project's health at a single glance.

Part 2 : Detailed Interface Guide

This document details the use of the different modules in the SmartBimPeï suite.

1. Clash Detection (Clash Detector)

This module is the core of SmartBimPeï. It allows you to analyze two models (or a model against itself) to detect physical intersections (clashes) between elements.

1.1 Analysis Configuration

Element Description and Operation
Model A / Model B Select the target file (Host Model or Linked Model) for each model. The detection will be run between these two models.
Element Categories Check the Revit categories to analyze for each model (e.g., Walls, Floors, Ducts, Pipes).
Level (Filter) Allows restricting the analysis to one or more specific levels of the building to target results.
Sliver Tolerance (mm) Overlap margin tolerated. If two objects touch over a depth less than this tolerance, the clash is ignored.
Min. Size (Model A & B) Excludes elements that are too small from the analysis (e.g., ignore pipes with a diameter less than 90mm).
Auto-Provision Margin Adds a safety margin (in mm) around the clash when creating a provision for void box.
Parameter Filter Allows precisely targeting certain elements (Exact Parameter Name and Expected Value).
Network Orientation Filter (Optional) Target only Horizontal or Vertical networks in the detection.
Button: Detect Starts the detection scan. The results will be displayed in the grid on the right.

1.2 Exports and Render Mode

Element Description and Operation
Save XML / Load XML Allows saving the current state of your detection (with resolved/active clashes) and reloading a previous session.
Export BCF / Import BCF Standard exchange format (BIM Collaboration Format) to send clashes to third-party coordination software (Navisworks, BIMcollab, etc.).
Render Mode (PDF/BCF) Defines how the software should interpret the clash for the provision for void:
- Automatic: Deduces the action according to the nature of the Host Model.
- Force Structure Mode: To see/generate the penetrations (actual holes).
- Force MEP/Coordination Mode: To see/generate the requests (orange boxes).
⚠️ Data Flow and Sharing (XML File)
At each detection, SmartBimPeï saves your results in an .xml file generated automatically in the same folder as your Revit file (.rvt).
To share your analysis with other stakeholders (e.g., Structural Engineer), always send them the .rvt model AND the .xml file in the same folder. They will then see the entire clash history directly in their interface!

2. Module 4: BIM Audit (Unified Version)

This module now centralizes all quality control for your model. It merges the former data verification tool with the Audit system, allowing you to instantly validate compliance with your BIM Execution Plan (BEP) or shared parameters.

2.1 Main Window (Running the Audit)

Control Description
Audit Profile (Dropdown) Select a pre-configured system profile or choose a custom profile (BIM Charter) you have created.
Create / Edit Rules Opens the BIM Charter Editor to modify the selected profile or create a new one.
Run Audit Scans the entire Revit model according to the chosen profile's rules and displays the list of non-conformities (Element, Severity, Description).
Auto-Resolve Attempts to automatically fix certain common errors selected in the list.
Export CSV Exports the audit results to an Excel-compatible CSV file for your coordination reports.

2.2 BIM Charter Editor (Creating Rules)

This is where you define the strict data rules for your project.

Control Description
Generate from TXT (Shared Parameters) Key Feature. Directly import the shared parameters .txt file provided by the BIM Manager. The plugin will automatically generate all the necessary rules to check if these parameters are present!
Add a rule Adds a blank row to create a manual rule. You can check naming conventions (using * wildcard), parameter presence, or exact parameter values.
Delete Selection Removes the currently selected rule in the grid.
User Guide Displays quick help on how to use input masks.
Save Charter Saves your custom rules under the profile name entered at the top left.

3. Duplicate Detector

This module scans the model to quickly identify overlapping elements (modeled twice in the same place).

Element Description and Operation
Categories to scan Check the object categories where you suspect duplicates (e.g., Walls, Plumbing fixtures, etc.). Very useful for checking imports or copy-paste errors.
Blue button: Detect duplicates Analyzes the selected categories and displays the list of perfectly overlapping elements in the results table (with their ID and location).
Red button: Delete copies Automatically deletes one of the two duplicate elements to clean up your model.
Important note: This button will only delete duplicates present in your Host Model. If the duplicate comes from a Linked Model (IFC or RVT), it will be ignored because Revit prohibits modifying links (read-only).

4. Quantity Extraction (Global Takeoff)

This module generates precise quantities (lengths, areas, volumes) from your model to prepare your estimates and costing.

Element Description and Operation
Filters (Model, Level, Category) These drop-down menus at the top become active after extraction. They allow you to quickly filter the table display (e.g., only show Level 1).
Red button: Run Extraction Scans the entire model (and its links) to extract the complete list of elements with their actual physical quantities.
Blue buttons: Isolate / Restore Select a row in the table and click 'Isolate' to only show this object in 3D in Revit. 'Restore' cancels this isolation.
Green button: Export Estimate (.xlsx) Generates a perfectly formatted Excel file containing all the data from your table, ideal for costing.
Import/Export buttons (.sbp) Allows saving your current table (and especially your entered unit prices) to a proprietary .sbp file to reload it later.
Total Estimated Amount Dynamically updates at the bottom right based on the unit prices you entered in the table.

5. Dashboard (Global Dashboard)

The control center that monitors the health of your projects and the progress of your BIM coordination.

Element Description and Operation
Progress charts Visually displays the ratio of "Resolved" vs "Active" clashes by reading the data from your XML file.
Health Indicator (Score) Overall score given to your model based on data quality (parameters) and the presence of duplicates.
Button: Refresh data Forces a reread of the XML file and the model to update all your charts in real time.
